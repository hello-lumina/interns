# Lumina Studio — Interns

Repo treningowe dla praktykantów Lumina Studio.

## Workflow

1. Sklonuj repo.
2. Utwórz branch do swojego zadania.
3. Wprowadź zmiany.
4. Zrób commit i push.
5. Otwórz Pull Request do `main`.
6. Poczekaj na code review.
7. Wprowadź poprawki po review.
8. Po akceptacji PR zostanie zmergowany.

## Branch naming

Przykład:

```bash
feat/001-first-pr
```

Nie pushujemy bezpośrednio do `main`.
