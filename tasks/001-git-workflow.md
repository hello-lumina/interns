# Task 001 — Git workflow

## Cel

Przećwiczyć pełny workflow: branch → commit → push → Pull Request → code review → poprawki → merge.

## Zadanie

1. Sklonuj repo.
2. Utwórz branch:

```bash
git checkout -b feat/001-first-pr
```

3. W folderze `profiles` dodaj plik ze swoim imieniem, np.:

```text
profiles/yana.md
```

4. Dodaj w nim:
   - imię,
   - technologie, które już znasz,
   - czego chcesz nauczyć się podczas praktyk.

5. Zrób commit.
6. Pushnij branch.
7. Otwórz Pull Request do `main`.
8. W opisie PR napisz krótko:
   - co zmieniłaś,
   - jak sprawdzić zmianę.

Po otwarciu PR dostaniesz code review.
